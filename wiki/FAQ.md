# Frequently Asked Questions

### Does PrettyFrogs add new frog mobs?

No. Existing vanilla adult frogs gain cosmetic forms and render layers. Their underlying vanilla identity stays intact.

### Does transforming a frog change which froglight it produces?

No. Froglights are governed by its original warm/temperate/cold vanilla variant.

### Are forms inherited by baby frogs?

No. Breeding is vanilla, and transformations are not inherited.

### Can I transform a tadpole?

No. The right-click transformations are for **adult** frogs.

### Can I remove a transformation?

Yes. Use a **Milk Bucket** on the transformed frog.

### Can I change a frog's color repeatedly?

For **Watermelon, Poison Dart and RGB families**, repeating the same trigger cycles variants. For **Crystal**, a different supported cluster changes the source color. Other single-form triggers do not consume a second item when nothing would change.

### Is the RGB rod part of PrettyFrogs?

No. Its registry ID is `colorful_rods:rgb_end_rod`. This optional integration is only active when that item exists.

### What does the HD toggle change?

Only the eight texture files that were changed in the HD texture merge; the other frog textures and dedicated custom model atlases stay the same. See [[Appearance Settings]].

### Does turning off Extra 3D Decorations hide the Tadpole Costume?

No. It hides only the shared decorations for Crystal, Mushroom, Water, Cake and Ice frogs.

### Can my friends use a different appearance setting?

Yes. HD/3D switches are **local client preferences**, not server settings.

### Can I make the Frog Field Guide?

Yes. A **Book + Tadpole Bucket** produces the Field Guide and returns an empty bucket. See [[Crafting and Recipes]].

### Can I use Blockbench to edit custom models?

Yes. The build workflow packages reference Java model source and PNG atlases, but not ready-made `.bbmodel` exports. Keep UVs and animation hierarchy consistent. See [[Textures and Blockbench]].

### Is Caszual Additions required?

No. The mod lists Fabric API, Fabric Loader and Minecraft as core dependencies. Some transformation integrations (the RGB End Rod in particular) need their separate item's provider mod.

### Where do I get updates?

Visit [GitHub Actions](https://github.com/CaszGamerMD/PrettyFrogs/actions) for successful build artifacts, or [Releases](https://github.com/CaszGamerMD/PrettyFrogs/releases) when a release is published.
