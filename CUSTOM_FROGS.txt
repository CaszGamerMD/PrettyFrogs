PRETTYFROGS - CUSTOM FROG REFERENCE
===================================

This file is the canonical human-readable reference for PrettyFrogs custom forms.
IMPORTANT FOR DEVELOPMENT: Whenever a new frog form is added, update this file in the same change.
The Field Guide / book GUI should use this list as a content reference and stay synchronized with FrogFormRegistry / FrogGuideEntries.

GENERAL RULES
-------------
- Adult frogs only. Tadpoles and baby frogs remain vanilla.
- Right-click an adult frog with the listed transformation item.
- The underlying vanilla warm/temperate/cold frog identity is preserved.
- Forms are cosmetic and are not inherited through breeding.
- Froglight behavior still uses the underlying vanilla variant.
- Every original appearance has an additional Polished appearance. All new textures and accessory atlases are 48x48.
- Existing frogs keep their saved appearance. No original form IDs are replaced.
- Reapplying the trigger cycles through the original appearances first, then their Polished counterparts; Survival consumes the trigger normally.
- If one trigger item has multiple frog variants, using that item again cycles to the next variant and consumes the item normally.
- Survival consumes transformation items where appropriate; Creative does not.
- Milk Bucket removes the custom form and restores the normal appearance.
- Water Bucket is intentionally not a transformation trigger.

CUSTOM FROGS
============

1. Watermelon Frog
   Trigger: Melon Slice
   Variants: 4. First use selects randomly; repeated uses cycle original green, original red, polished green, polished red.

   - Red-pink seeded top / green striped belly

5. Muddy Frog

6. Water Frog

   Trigger: Ice Block

9. Dart Frog
   Trigger: Poisonous Potato
   Result: First use selects a random Dart Frog. Additional Poisonous Potatoes cycle through:
   - Original dartfrog_1 through dartfrog_8, in order
   - Polished dartfrog_1 through dartfrog_8, in the same order
   Total: 16 appearances. Legacy red/blue/yellow/green/orange IDs still resolve to their existing equivalents.

    #prettyfrogs:crystal_clusters

25. Tadpole Costume
    Trigger: Tadpole Bucket

POLISHED APPEARANCES
====================
- All 37 original appearances gain a distinct ID ending in _polished.
- All 37 originals remain available, giving 74 custom appearances across 25 trigger families.
- Polished glow masks follow the new skin markings; RGB masks retain runtime color animation.
- Polished water, ice and slime shells match their corresponding skins.
- Cake candles, crystal material, particles, bucket storage and vanilla frog variants continue to work.
- The Field Guide lists each original beside its Polished counterpart.
- The appearance-resolution toggle continues to control original textures; Polished assets remain 48x48 in either setting.

RESET
=====
Milk Bucket
- Removes the PrettyFrogs cosmetic form.
- Leaves the frog's underlying vanilla variant intact.

DEVELOPMENT / FIELD GUIDE RULE
==============================
When adding, renaming, removing, or changing a frog:
1. Update FrogFormRegistry / transformation logic.
2. Update this CUSTOM_FROGS.txt reference in the same commit.
3. Update FrogGuideEntries so the in-game Field Guide matches this reference.
4. Add/update the frog texture, overlay, particles, and trigger information as applicable.
5. Keep special families (Watermelon, Dart Frog, and Crystal Frog) represented accurately in the guide.
6. When multiple variants share one trigger item, repeated uses of that item must cycle through the variants.

Current trigger families: 25
Custom appearances: 74 (37 original + 37 Polished)
Dart Frog appearances: 16 (8 original + 8 Polished)
Crystal Frog appearances: determined by the exact supported crystal cluster.
